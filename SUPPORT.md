# Support

These are personal / small projects with **no SLA**. Response times are
best-effort.

## Have a question?

Check the repository's own README and CONTRIBUTING first, then open a
**Question or idea** issue, or a Discussion where the repository has them
enabled.

## Found a bug or want a feature?

Use that repository's issue templates, **Bug report** or **Feature
request**. Include enough detail (repro steps, version, environment) for the
report to be actionable.

## Security issue?

Do not open a public issue. See that repository's `SECURITY.md` for private
reporting instructions.
